# 🏫 School Website

A simple and responsive **School Website** designed to provide students, parents, and visitors with important information about the school.

## ✨ Features

* Home page
* About School
* Courses / Classes
* Teachers
* Gallery
* Events & Notices
* Contact Us
* Responsive Design

## 🛠️ Technologies Used

* HTML5
* CSS3
* Bootstrap
* JavaScript

## 🚀 Purpose

This project was created as a frontend web development project to practice building a clean, responsive, and user-friendly school website.
